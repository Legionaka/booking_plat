# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for `Legionaka/booking_plat` when it is enabled; this is the preferred reporting route. If private reporting is unavailable, contact Legion Cunningham at Legioncunningham@gmail.com. Include affected versions, impact, and reproducible steps. Do not include real credentials, payment data, or customer records.

Please allow time to investigate and coordinate a fix before public disclosure. This project has no formal service-level agreement.

## Scope

Report vulnerabilities in this repository's application, deployment configuration, or documented interfaces. See [docs/security.md](docs/security.md) for the threat summary and known limitations.
