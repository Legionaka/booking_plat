# ADR 0006: Documentation reflects the shipped product

- Status: Accepted
- Decision: Keep `docs/planning.md` as the current implementation and deferred-work source, and use `docs/README.md` as the index. Record future work explicitly instead of describing it as shipped.
- Reason: Earlier planning text described routes and features that were no longer accurate after implementation phases.
- Consequences: Documentation contracts check routes, links, and environment-variable coverage. Quality results must be refreshed from actual runs.
